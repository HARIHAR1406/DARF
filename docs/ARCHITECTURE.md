# Architecture

DARF utilizes a strict phase-based modular architecture.

## Phases
1. Auth & Core Setup
2-7. UI & Business Logic Expansion
8. Prompt Layer
9. Destructor, Rebuild, Analysis
10. Orchestration, Provider, Execution, Agent, Knowledge, Learning

## Core Principles
- Complete Modularity
- Zero Circular Dependencies
- Strict Singleton Services
- Deterministic Execution paths
